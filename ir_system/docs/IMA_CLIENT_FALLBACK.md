## 执行约定

- API 优先。支持辅助功能的 macOS 版本已接入固定客户端执行器；API 额度耗尽后自动切换，
  仅使用正常提供的下载功能；不读 Cookie、不抓私有接口、不复制签名地址、不绕过客户端限制。
- 沿用原任务已选择的知识库 ID、名称和北京时间范围。不得扩大到所有订阅或自动改为次日。
- 标题日期、客户端列表日期、资料发布日期分别记录。短日期的年份或日期语义无法核实时，
  归入待核验，不假定标题日期就是上传日期，不宣称当天完整覆盖。
- 保留 API 断点和原件。新下载记录使用稳定材料 ID、来源库和哈希去重；只通过公开
  `ir_search` 入库接口接入，不手改桌面任务状态或完成标记。
- 仅文字及非音频附件；音频、OCR、转写仍单独授权。保存后核验文件实际存在、完整性及哈希。
- 页面无下载按钮或明确拒绝时，记录该项限制，不能用截图／缓存提取替代导出。

## 运行边界

- 仅 macOS。首次需要本人在系统设置授予辅助功能权限；仅提示，不自动授予。
- 客户端可能弹出窗口并使用鼠标；下载时不要同时操作 IMA。焦点变化时保存断点，避免误操作。
  星球的无头浏览器仍独立后台运行。IMA 客户端不承诺完全后台。
- 对同名库、目录结构不匹配、缺少日期、无法核对总数、文件夹或无扩展名内容，保留缺口，
  不把滚动停止或未找到下载按钮当成“整库完成”。未支持所有客户端页面布局。
- 短日期按最近年份推定且保留原始显示值；它是客户端列表日期，不是经过验证的发布日期。
  不使用文件名日期；不能证明北京时间某日全部更新。原件入库日期保持 unknown。
- 官方保存前没有可靠大小：先保存到任务临时区再校验，单次网络流量不保证硬性封顶。
- 批次边界自动续传；权限、登录、安全锁、客户端结构变化与平台明确限制仍会报告。
  只有没有缺口的流程才显示完成，`coverageComplete` 始终不能凭 UI 扫描改成 true。
