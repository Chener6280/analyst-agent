当前流程：先点信源“预分析”状态，查看前置问题 → 处理后重新扫描、确认选择并检查本地环境 → 绿色“可更新”后选择更新历史或更新到最新，确认日期与预算。灰色不是已经通过，琥珀色列出具体阻碍。真正下载前仍会复查。LLM 按需介入非语音处理；语音单独授权并后置，不是每次下载后的必做步骤。

外部 Pi / CLI 报告不会自动解决桌面任务或接通网页下载路线。用户确认新的更新任务后，桌面自动替代旧任务重叠范围，先停止仍在运行的旧任务，再使用新断点；原件与审计记录保留。未重叠范围可按旧断点续传。请使用用户本次明确日期，年度命令只是示例，不能覆盖本次范围。不要因归档根目录存在零字节 `.writer.lock` 就要求删除：根锁须核验实际持锁进程，派生索引的排他锁则另行核验；任何锁均不自动删除。

## 如何使用

1. Data Center 配置本机 Python、安装了新版 ir_search 的环境及归档目录。目录须已存在；已有归档保留，新采集只写 `incoming/v1/`，原 `index/archive.sqlite` 和原件不修改。
2. 在「发现／添加订阅」选信源，点击扫描并确认联网。每次真正下载前还会再次扫描本轮信源完整目录。新订阅仅进入候选，不自动启用。智堡是固定栏目目录，其访问能力在读取时验证；知识星球当前 API 目录不证明会员有效期，网页会员扫描尚未接入此按钮。
3. 在「信源与执行设置」读取 IMA Excel（只读），将每行绑定到扫描得到的真实知识库 ID，确认加入草稿。`需要下载` 对应一次性，`优先下载` 对应持续增量，`暂不下载` 对应不下载。没有 ID 不猜，重复名称不自动匹配，Excel 公式不执行。
4. 为启用的集合填写首次起点，检查预算，保存。日期明确属于 Asia/Shanghai。IMA 没有可靠发布日期，实际枚举目录、保留未知日期，不伪称按所填起点过滤了内容。
5. 执行方式选择 Pi，或选择不调用模型的固定流程。Pi 使用其**保存的默认模型**；其他 Pi 会话中的临时选择不一定是该默认值。请先在 Pi 确认默认模型及账号额度。「检查 Pi」只运行帮助检查，不调用模型。若桌面找不到 `pi`，填写本机 Pi 可执行文件的完整路径，不填写带参数的命令。
6. 点击「同步新增资料」或「一次性历史回补」，确认范围与本轮预算。Pi 只调用已批准的启动工具，程序后台完成任务；不会逐文件消耗模型推理。
7. 查看运行记录。需要时点击「用 Pi 解释报告」，再次确认模型调用；此解释会话只有报告读取权限，不能启动／停止下载。程序统计为准，模型文字不替代状态。

## Pi 与 Kimi 的边界

- 已接 Pi；不传 `--model`，不复制或导出 API Key，沿用用户 Pi 配置。
- 使用四工具白名单、禁用内置工具和其他扩展发现、禁用 Skill／上下文／提示模板自动加载、禁用会话复用，工作目录隔离。
- 仅向本机临时端口提交四种固定请求；短期随机授权只在受信任扩展内使用，不进入模型提示。来源名称、文件标题、正文、原件与下载签名地址不发送给模型。
- 最多 12 次工具请求、4 个模型轮次，单次 CLI 调用最多约 120 秒；超量会中断。供应商费用不一定能即时获得，token 阈值在响应后检查，不能保证绝对金额封顶。界面记录每次调用的供应商返回 token，不伪称免费。
- 模型工具限制不是针对恶意 CLI 二进制的操作系统沙箱；Pi 本身及显式加载的扩展仍是用户信任的本地程序。
- Kimi Code CLI 已核对安装与帮助，但其独立受限配置尚未验收，暂不从此按钮直接启动。不以 `--auto`／全权限模式代替安全接入；可以使用用户自行在 Pi 中配置的模型渠道。
- 普通网页／客户端 computer use 不开放给便宜模型；当前聊天自带工具不是桌面包的运行依赖。

## 数据与状态

- 桌面本机设置、任务、授权、每集合进度：Electron 用户数据目录中的 `sync-v1/`。模型不能修改它们。
- SDK 标准化新增资料：归档下 `incoming/v1/records`；新原件：`incoming/v1/objects/<前缀>/<SHA256>`。复用旧文件前校验大小和哈希，读取旧数据库时使用只读连接。
- 不同知识库引用同一材料时分别保留集合来源；物理原件按哈希共享。IMA 材料与附件即使同一个 ref，也使用不同本地文档 ID，不覆盖主题记录。
- 每页位置、子文件夹队列、附件及解析待办持久化。页面内容在续传期间变动时暂停报告游标失效，不猜下一页。只在本轮成功时推进集合完成日期。
- 有日期的来源重叠回扫，IMA 重新遍历目录并按 ID 去重。未验证来源在稳定 ref 下替换附件的版本语义，不能承诺捕获所有历史编辑／内容替换。
- 日常按钮不处理 once 库。一次性回补完成后不会再次自动启动；现存一年归档缺口不由一个成功增量任务抹去。
- 停止通常完成当前有时限的操作后生效。正常关闭应用会保存进度；重新打开后由用户授权续传。强制杀进程如遗留旧 SDK 的 `.writer.lock`，仍须维护者核验，不自动清锁。新的同步根锁由操作系统释放，不依靠删除 PID 文件恢复。

## 暂停与缺口

- OCR、无效文件、不支持格式、权限／认证、分页异常等都保留并报告，不无限重试。已完成下载不重下。
- 已授权预算耗尽、正常停止和中断可通过「授权续传」继续原范围。可以在保存新的预算后明确授权新一轮，不会自动拆批绕过预算。
- 未解决的失败／partial 任务阻止同一归档悄悄创建新任务绕行；当前需维护者核查。尚未提供用户逐项确认跳过缺口的管理界面。
- 第一版 IMA 笔记、网页正文路由尚未接入；发现后记录缺口，不把元数据当全文。PDF、Office 等通过正式附件接口获取；图片可能进入需要 OCR／不支持格式的暂停项。
- ZSXQ 图片原件不在当前 API 下载通道内，保留覆盖缺口。智堡供应商摘要保留 abstract，不宣称研报原件。
- 音频、视频只记待办，不下载；ASR 和托管 OCR 不会被这个入口调用。SDK 在真实附件元数据阶段再次核对媒体范围。
- 字节统计为成功落盘字节。原件请求有单次传输上限；元数据响应及失败请求的传输量不完全计入该统计。

## 独立安装与验证

桌面和 ir_search 仍分开安装；适配器只调用公开 SDK。新版需要公开的 `list_collection_directory`、`ingest_local_record`、`ingest_local_asset`、`inspect_ingested_record`，以及 `retrieve_asset(media_policy=...)`。缺失时停止，不临时安装或修补。

桌面打包包含 `sync_worker.py`、只读 Excel 预览器和 Pi 扩展，但不包含 Python、Pi、用户模型配置、私人库列表或登录凭证。换电脑需安装依赖、配置路径并登录。当前只验证 macOS arm64；Windows／Linux、签名、公证及应用退出后的定时同步另行验收。

开发验收入口：`npm run check`、`npm run test:sync-ui`、`npm run test:pi-offline`；Python Worker 测试位于 `tests/test_sync_worker.py`，需使用能导入本轮 SDK 和解析依赖的 Python 环境。所有默认验收使用合成资料／隔离目录，不点击真实联网扫描或调用付费模型。

下一步上线前，需要用户选定一次小范围真实信源验收，并确认使用 Pi 的模型额度。离线通过不等于登录、限流、下载权限和付费模型链路已经在线验证。
