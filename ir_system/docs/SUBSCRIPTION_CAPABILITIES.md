# 子订阅下载能力与方法

预分析检查运行环境；订阅列表记录下载能力，两者不能混为一个绿灯。

| 方法 | 可下载依据 | 模型参与 | 桌面接入 |
|---|---|---|---|
| API 直接下载 | 原件样本实际读取成功 | 不需要 | 已接入；逐文件检查 |
| 固定浏览器程序 | 星球会员有效、允许附件下载、可走网页通道 | 不需要 | 已接入，可能需本人扫码 |
| Computer Use 操作官方客户端 | 通过官方下载入口实际保存文件并核实大小／校验和 | 本次由模型定位和操作 UI | IMA 批量通道尚未接入 |
| 其他 | 必须记录实际方法及下载实证 | 据实记录 | 未验证不宣称支持 |

API 拒绝不能单独证明整库不可下载。官方客户端明确显示不可导出时，不通过缓存、临时地址、复制或截图绕过。一个样本的结论不代表所有文件或全年完整性；列表的依据中注明抽样边界。空目录、未找到样本、技术错误均为待核验。

下载证据不因每日打开软件而失效；保留核验日期。新的订阅、已知会员／权限变化显示问号，必须由用户确认选择。已确认不可下载的项例外：启动或扫描完成后默认打叉（不采集），包括会员过期、平台禁下载、客户端样本明确禁导出或库已删除。API 拒绝、超时、未找到样本不作此处理。新库不会自动加入下载范围。订阅过期按实际时间计算，旧绿灯不能覆盖过期。

自动取消是可追溯的默认选择，记录原因并撤销未使用授权，不修改旧任务、断点或覆盖水位。同一证据不会在每次轮询／重启反复覆盖用户后续的明确选择；但用户重新勾选不能绕过执行时的权限保护。后来确认为可下载，转为问号重新确认，不自动打勾。

主列表只显示下载结论与方法，不再显示整块 API 样本诊断表。按需从某库的“查看原因与方法 → 高级：重新核验／技术详情”进入单库诊断。底层仍区分 API 与官方客户端通道；客户端成功不授予 API 权限。用户可显式诊断一个未勾选但当前可见、已确认的库，须单独确认联网，不将其加入下载范围。后台批量诊断仍只覆盖已选范围。

“更新历史／更新到最新”的运行标记来自真实任务状态，只标亮匹配信源和更新类型的按钮。运行时蓝色加转动标记，并按阶段显示准备、扫描、下载、入库、解析、收尾；同时显示该任务已下载份数，不伪造百分比。限流等待改为静态琥珀色“等待处理”；预算暂停、失败、停止或完成后清除动画。普通订阅扫描与样本核验不冒充下载。系统减少动态效果设置下关闭旋转，仍保留文字与颜色。

维护者可在本机应用数据目录提供 `capability-audit.json`，经严格字段校验后在启动时一次性导入目录与官方客户端证据。不把此文件打包给其他电脑；不包含凭证、正文或临时下载地址。导入后按上述默认选择规则处理不可下载项，其余选择保留；不修改归档或检查点，也不把客户端证据当作 API 授权。较新的在线目录不会被旧审计覆盖。运行中的应用不被外部强制改写状态。
