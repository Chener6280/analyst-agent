# 智堡栏目选择与中文显示

智堡的九个固定栏目在信源管理表格的「子信源」下拉入口统一勾选、保存。历史、最新和合并更新共用已保存的选择；更新窗口只确认日期及只读范围，不再修改栏目。取消弹窗不保存；清空后保存允许停用全部栏目，不自动恢复全选。现有选择保持不变，首次没有任何配置时在选择窗口预选九栏，仍须保存。

中文名是 IR System 的显示名称，下载、断点、去重仍使用原来的栏目 ID。不修改 ir_search。

| 栏目 ID | 显示名称 | 内容说明 |
|---|---|---|
| ib | 投行研报 | 投行宏观、策略等研报笔记 |
| company | 公司研究 | 公司、行业研究及相关资料 |
| am | 资管报告 | 资管机构的投资观点与报告 |
| archive | 央行·政府·智库 | 机构公开文献、政策及研究资料，不仅是历史档案 |
| ec | 财报电话会 | 财报电话会及相关纪要，不保证逐字稿 |
| feed | 投研资讯流 | 综合资讯流，可能与其他栏目重复 |
| market_daily | 市场日报 | 市场动态与每日观察 |
| article | 智堡研究 | 智堡文章，包括全球市场日志等 |
| mikko | Mikko 市场短评 | Mikko 的短篇日志与市场观察 |

命名依据：ir_search 的智堡素材适配说明，以及 2026-09-27 调用公开 `export_collection_timeline` 对九栏各抽取两条近期样本。窗口 2026-08-27 至 2026-09-27，北京时间；max_items=2，每栏 context 最多 5 次操作，实际各 3 次。九栏均取得两条记录，诊断为空；status=partial 是主动样本数量上限，不是全量完成。只读抽查，未写入归档、未下载附件、未调用生成模型。样本主要为标题及 Mikko 列表正文，不据此保证每篇的体裁或事实准确性。

研报、文献和电话会通常是智堡笔记摘要，不因中文名含“研报”就代表拿到了原件；文章和日志的正文范围以接口标记为准。
