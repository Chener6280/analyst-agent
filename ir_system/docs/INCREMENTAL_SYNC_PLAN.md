# 一键增量同步与低成本 Agent：项目计划

日期：2026-09-26。

状态：P0–P3 的 API／Pi 开发版已落地并进行离线验收，真实信源／付费模型端到端验收待授权；P4–P5 的完整范围尚未完成。实际用法和限制以 [开发版说明](INCREMENTAL_SYNC.md) 为准。下文保留原计划，不把规划能力当成现有能力，也不替代既有操作合同。

## 1. 交付目标

用户在 ir_system 点击「同步新增资料」，低成本 Agent 在用户已保存的范围内启动同步、观察结果并报告；程序完成订阅扫描、权限检查、发现新增、下载非音频资料、解析和索引更新。再次点击不重复下载已有原件；中断后能够安全续传。

第一版在本机 macOS、应用运行期间执行。关闭应用时安全停止并保存进度，重新打开后由用户续传；不承诺关机、睡眠或退出应用后仍运行。无人值守每日调度另立后续阶段。

核心原则：**高能力维护者负责建设和维修，低成本模型负责受限操作与解释，程序负责执行和数据正确性，用户负责范围与费用授权。**

## 2. 职责与权限边界

| 工作 | 我／高能力维护者 | 低成本 Agent | 确定性程序 | 用户 |
| --- | --- | --- | --- | --- |
| 架构、接口、权限规则、升级兼容 | 设计、实现、测试 | 不修改 | 强制执行合同 | 确认重大行为变化 |
| 选择信源、一次性或增量、首次起点 | 提供建议 | 不自行扩张 | 保存配置并验证 ID | 决定和确认 |
| 扫描订阅、判断会员与通道 | 实现及修复判定逻辑 | 读取结构化结果，不猜测 | 扫描、判定并记录证据 | 新订阅选择是否启用 |
| 启动增量任务 | 开发入口 | 使用按钮生成的授权令牌启动 | 校验范围、预算、版本及重复请求 | 点击按钮授权本轮 |
| 翻页、递归目录、下载、哈希、断点 | 实现并验收 | 不逐文件推理，不修改游标 | 全部执行 | 通常无需介入 |
| 解析与索引 | 实现并验收 | 不生成或补写来源正文 | 按预算执行和校验 | 决定 OCR 等例外 |
| 限流、权限、登录、异常 | 修复程序缺陷 | 原样报告错误码和下一步 | 按已批准策略暂停或冷却 | 登录、批准重试或调整范围 |
| 音频／付费服务 | 后续独立接入 | 不能在文字任务中调用 | 阶段隔离及费用开关 | 单独授权 |
| 日常报告 | 设计报告口径 | 用任务结果写简短说明 | 提供权威统计与清单 | 查看与处理待办 |

低成本 Agent 不拥有通用终端、源码写入、数据库写入、Cookie 导出、任意网址访问或任意浏览器操作权限。不得安装依赖、修改下载器、清理锁、重置断点、变更订阅、绕过复制／下载限制、修改预算或自动切换更贵模型。

“交给我处理”指生成可检查的故障交接包，由用户交给维护者；不代表后台自动唤醒当前聊天、发送到其他聊天或产生高价模型调用。

如以后委派低成本模型辅助开发，仅限明确授权的文案、文档、测试样例等独立任务，经维护者审查后合入；不能让日常下载 Agent 自我修改生产代码。

## 3. 按钮按下后的流程

1. **读取已确认设置**：来源、集合 ID、采集方式、首次起点、媒体范围、运行／流量／模型预算。缺少首次起点时请用户选择，不默认为全年回补。
2. **重新扫描**：知识星球扫描所有当前星球并分别记录会员状态和通道状态；IMA 完整扫描当前可见库目录；智堡检查固定九栏目及实际访问能力，不伪称存在订阅目录。
3. **显示变化并生成计划**：新发现未配置的集合进入「待选择」，不自动启用；无法可靠匹配的库名不猜 ID。扫描不完整时不使用旧快照冒充最新完整清单，也不启动该来源的新下载计划。
4. **冻结本轮范围**：由程序生成不可由模型扩张的计划和授权令牌。计划包含配置版本、扫描版本、时间范围或枚举范围、媒体类型、预算、允许通道及已确认例外。
5. **便宜 Agent 启动**：只能启动这份计划。程序立即返回 job_id；下载在独立任务中进行，不占用一次普通桌面请求直到下载结束。
6. **程序采集与入库**：发现新增／变化 → 下载文字及非音频附件 → 校验原件 → 解析 → 更新索引。每一步独立记录状态；发现音频仅记录元数据与待办。
7. **结果展示**：程序先展示权威统计，Agent 再给简短总结。失败时保留原件和进度；登录、权限、未知故障或预算不足显示清晰的处理入口。

首次配置后，同一已批准范围内的正常点击无需逐文件确认；新增库、范围扩大、新通道授权、额外费用和超预算不能靠模型自行确认。

按钮旁设「信源设置」「历史回补」「运行记录」「停止」。停止在安全边界生效，下载有超时，不无限等待当前文件。日常按钮不隐式续跑所有历史任务。

## 4. 用户策略的落地

依据用户截至本计划日期标记的 IMA Excel，待导入并校验：

| 用户标记 | 配置含义 | 后续行为 |
| --- | --- | --- |
| 需要下载：10 个库 | once | 单独历史回补；验收后退出日常同步；保留缺口，不以预算耗尽视为完成 |
| 优先下载：11 个库 | incremental | 明确首次回补范围，建立基线后日常增量 |
| 暂不下载：5 个库 | off | 不采集；仍可在订阅目录扫描中显示其存在 |
| 新发现／标记不明 | pending_selection | 提示用户选择，不自动启用 |

新增三个“爱研报”库尚需绑定真实 ID 和验证通道。名称不作为唯一键；同名、改名、缺 ID、重复行都必须报告。导入先预览，不改用户 Excel；落地配置保存在用户本机，不把私人库清单写入发布包。

知识星球和智堡也使用相同的显式选择原则；过往历史下载范围不自动等于长期每日增量授权。

第一版只处理文字与非音频附件。音频下载、火山转写、托管 OCR 不挂到主按钮；以后仍遵守文字阶段验收 → 音频下载 → 单独授权转写的顺序。

## 5. 技术边界与隔离

### ir_system

- 界面、来源策略、用户授权、任务调度、任务日志、进度及结果展示。
- 可替换的低成本 Agent 适配层；配置模型和调用渠道，但不依赖某一个聊天产品会话。
- 独立任务管理协议，拟称 `ir-system-sync/v1`。保留现有 `ir-system-provider/v1` 的本地阅读与索引接口，不破坏旧调用者。
- 知识星球网页及未来 IMA 客户端执行器放在独立适配器层，只使用已验证的官方可用操作。

### ir_search

- 正式公共 API：来源目录、内容枚举、检索／读取、授权附件获取、解析和本地索引等。
- 补齐已验证的 IMA 文件列表与文件夹递归能力，不能长期依赖 `.local/` 审计脚本。
- 不在下载、增量判定和证据生成核心路径引入 LLM；不导入桌面 UI 或个人 Skill 路径。

### ir_archive

- 保存原件、来源证据、下载状态和可迁移的相对路径；继续尊重既有下载器对原始数据库的所有权。
- 同步调度账本记录每阶段结果并引用现有下载检查点，不另造一份互相冲突的下载权威状态。
- 写入遵守现有单写者锁；不并发破坏历史 CLI、解析器和桌面任务。

版本兼容检查必须先于执行；升级不兼容时报告适配器版本问题，不让便宜模型临场修补。无法保证 ir_search 任意破坏性变更都完全无需适配，但应将修改限制在公共接口／桥接层。

当前聊天里的 computer use 能力不是可直接打进 Electron 的通用 SDK。IMA 客户端路径要有独立可部署的执行器、权限申请和目标系统测试；未做到时界面明确「需人工协助」，不宣称所有模型都能直接调用该能力。

## 6. 增量、断点和完成口径

- 以来源＋集合 ID＋稳定材料 ID 判重，附件按来源引用关联、按内容哈希复用物理文件；不因同一 PDF 出现在两个库而丢失来源关系。
- 有可靠日期的来源采用逐集合进度和已配置的重叠回扫，并记录可见修改；不能假设只查“昨天”绝不漏掉迟到内容。
- IMA 日期缺失时保存首次发现／最近发现时间，不编造发布日期。目录扫描与文件下载分开：可能需要分页遍历目录，才能知道哪些文件新增，但只下载新增或需校验更新的内容。
- 不假定 IMA 提供稳定增量游标、修改版本号或快照语义。分页期间变动、游标失效、嵌套目录、改名、重复 ID 都要测试；不能以首个已见文件作为停止条件，除非排序保证已验证。
- 分别持久化发现、下载、解析、索引状态。文件和下载状态成功落盘后才标记 downloaded；发现位置推进不得使待下载／失败条目从队列消失。解析失败可复用已下载原件，不重下。
- 首版可复用现有全量派生索引重建和解析缓存；后续有性能证据再改为增量更新。失败不得破坏旧可读索引。
- 既有归档不能因为“已经有些文件”就视为完整初始基线。迁移时核对历史范围与缺口；每日更新和历史欠账分别展示。
- 平台删除或取消订阅不自动删除本地历史原件；撤销采集授权停止后续获取，保留来源状态证据。

权威结果区分：本轮范围完成、部分完成、预算暂停、需要用户处理、运行失败、用户停止。各来源可有不同结果，不能把「任务执行过」「目录已扫描」「索引 ready」「无新增」等同于全部附件成功或全年覆盖。

报告至少包括本轮范围、扫描时间及完整性、新增／更新主题、附件发现数、实际新下载数与字节数、校验复用数、解析／索引数、待办与失败、未知日期、音频待办、用时及模型调用量。附件引用数与去重物理文件数分开，摘要与全文分开。

## 7. 低成本 Agent 的调用合同（拟建）

只暴露最小工具集；以下名字是接口设计，不是当前可运行命令：

| 工具 | 能做什么 | 强制约束 |
| --- | --- | --- |
| `sync.start(grant_id)` | 启动已批准计划，返回 job_id | 无集合、日期、路径或预算自由参数；重复调用返回同一任务 |
| `sync.status(job_id)` | 查看结构化进度 | 只能读取当前授权任务，限频 |
| `sync.report(job_id)` | 读取脱敏结果与交接信息 | 不默认返回正文、附件、凭证、签名下载 URL |
| `sync.stop(job_id)` | 安全停止任务 | 不删原件、不回退已提交状态 |

续传由用户点击入口及程序校验决定；Agent 不能用新的 start 绕过已耗尽预算、限流或错误停止。调度器负责分页、批次推进和等待；不让模型每下载一个文件或每轮等待都消耗一次推理。

建议日常模型只在启动和结束时介入，发生明确异常时补充一次说明。限制工具轮数、输入／输出 token、总超时和预算；不预先承诺固定金额，实际价格取决于用户选定渠道。若无法得到真实费用，只报告调用次数／token 和估算标记。

默认仅把脱敏状态与错误码发给模型。首次启用云模型须由用户选择供应商并确认这类数据会外发；库名称、标题等也可能敏感，默认不发送。密钥由执行器本机安全保存，不进模型上下文、Git、安装包或报告。

所有页面与文档内容作为不可信资料，不能转成执行指令。工具入参由程序校验，绝不执行模型生成的任意 shell 命令。

模型不可用时：已批准且已启动的程序任务可在原范围和预算内继续；界面用程序报告，模型故障不变成重复下载。若尚未启动，提示切换「固定流程模式」由用户继续。未配置模型不妨碍本地阅读，也不自动借用其他应用登录或付费订阅。

## 8. 错误与授权处理

| 情况 | 计划中的处理 | Agent 的边界 |
| --- | --- | --- |
| 新订阅／ID 不明 | 列入待选择或待绑定 | 不自行启用、猜 ID |
| 登录失效／验证码 | 暂停受影响任务，请用户完成官方登录 | 不导出 Cookie、不自动绕过 |
| 会员过期／下载禁止 | 保留会员与下载权限两个字段，报告对应证据 | 不把所有 denied 解释成过期 |
| API 拒绝但客户端可能可用 | 仅允许走已授权且已验收的客户端路径，否则报告待验证 | 不临场开辟绕行路径 |
| 限流／临时网络错误 | 只按该下载器已批准、已测试的有限重试规则执行；现有合同要求停止时就停止 | 不反复 start、不提高频率 |
| OCR／无效文件／不支持格式 | 沿用当前解析合同暂停并报告；已经下载的原件保留 | 不上传 OCR、不修解析器 |
| 未知异常／数据库或锁异常 | 停止、脱敏诊断、交给维护者 | 不清锁、不修数据库、不升级依赖 |
| 预算耗尽 | 保存待办并显示预算暂停 | 不拆成新任务偷偷续跑 |

若要将来实现“某文件需 OCR 时隔离该文件、继续其他文件”，必须单独调整并确认现有停止合同，再补测试；本计划本身不授权这一变化。第一版遇到真实问题允许暂停，这是安全边界而非承诺无人干预。

## 9. 分阶段施工与交付

工程粗估按一名维护者、复用现有代码、及时取得必要配置计算。不是数据下载耗时，也不是第三方权限一定可修复的承诺。

| 阶段 | 主要由谁做 | 交付与验收门槛 | 粗估 |
| --- | --- | --- | --- |
| P0 范围与合同 | 我设计；用户确认 | 策略模型、Excel 导入预览设计、首次起点、预算、错误规则、模型接口选择；新通道和费用不默认开启 | 0.5 天 |
| P1 任务与权限底座 | 我开发 | 持久任务账本、授权校验、状态／停止／恢复、互斥、模拟来源测试；重复启动不重复执行，非法参数被拒绝 | 1.5–2 天 |
| P2 API 与入库闭环 | 我开发；便宜模型只做授权后的验收操作 | 接知识星球官方通道、智堡、IMA 已验证样本可下载的库；补 IMA 正式目录递归和非音频过滤；下载后可在 Research 查到 | 1–1.5 天 |
| P3 按钮与便宜模型 | 我开发；用户选择模型并确认配置 | 来源设置、同步按钮、进度／报告、受限工具驱动；拒绝模型越权；模型离线可报告并安全恢复 | 1–2 天 |
| P4 网页／客户端扩展 | 我开发与逐库验证 | ZSXQ 网页接入统一任务；IMA 客户端执行器先单库试点，再按选择清单扩展；不具备独立执行能力的库仍标人工协助 | 3–5 天，存在不确定性 |
| P5 稳定性与部署 | 我验收；便宜模型运行固定测试清单 | 故障注入、真实增量重复运行、同平台干净环境安装／迁移测试；报告功能与权限覆盖 | 2–4 天 |

P0–P3：约 4–6 个工作日，交付“已验证 API 范围内可点击、可驱动便宜模型、可查结果”的版本，不宣称三家所有库都可下载。

P0–P5：暂按约 9–15 个工作日（约 2–3 周）规划；IMA 客户端自动化可能需要延长，或将部分库交付为人工协助。当前仅有客户端单文件成功证据，不能将其当作稳定批量通道。

Windows／Linux 客户端自动化、签名公证、应用退出后的常驻服务和每日定时调度不包含在上述首轮承诺内。桌面配置、SDK wheel、适配器和归档保持可迁移；每个新系统需重新验证并自行登录，不复制凭证。

## 10. 验收清单

1. 每个接入来源用经用户批准的小范围完成：扫描 → 发现 → 下载非音频附件 → 校验 → 解析 → Research 可检索阅读，并保留真实证据。
2. 同范围重复执行，未变化的原件新下载数为 0；存在真实新增时只处理新增／应更新项。合成新增用于离线测试，不冒充线上实测。
3. 在发现后、下载中、下载提交后、解析中分别中断；重启后不丢待办、不重复落成品、不破坏旧索引，计费不确定调用不得盲重试。
4. 超过两分钟的任务不被旧请求超时杀掉；停止、断网、应用退出均有可恢复结果。
5. IMA 目录递归、重复／失效游标、无日期、空目录、文件改名、扫描不完整都能正确显示；无法证明完整时保留缺口。
6. 新增库不自动下载，off 库不采集；once 库不会在日常按钮中重新回补；权限变化有记录。
7. 文字阶段音频文件下载数为 0，ASR 与托管 OCR 调用数为 0。类型不明时先暂停待确认，不先混合下载再搬走音频。
8. 一个文件需 OCR／格式不支持时遵守现有停止规则；Agent 不能把 partial 改写成 completed 或自行跳过。
9. 模型尝试扩范围、调预算、改路径、调用 shell／ASR 或跨任务复用／使用过期授权令牌时被执行器拒绝；同一有效授权的重复启动只返回原任务，模型超时不重复执行。
10. 日志与模型上下文不含密钥、Cookie、签名链接及默认禁止外发的来源正文；联网目标与下载地址由下载器验证。
11. ir_search 公共接口回归和独立 wheel 测试通过；桌面合同与界面测试通过；不兼容版本明确拒绝，不依赖个人 checkout／Skill 路径。
12. 报告区分本批完成、历史欠账和平台覆盖；不因程序成功而宣称全年、所有图片或所有附件齐全。

## 11. 启工前仅需落实的选择

- 便宜模型的调用渠道、模型配置及费用上限：优先选择用户已经有且允许程序化调用的渠道；聊天会员不自动等于 API 授权。未决定时可先实现与模型无关的底座和测试，不擅自接入付费渠道。
- 第一轮上线验收的来源、集合、日期／枚举范围和下载／解析预算；已有 Excel 是选择依据，不是立即执行全年下载的命令。
- 非 IMA 来源哪些集合长期增量；IMA 新库 ID 待扫描绑定。首次回补起点与历史缺口如何处理须展示给用户确认。

推荐先批准 P0–P3 的实施范围，得到真实可用的按钮；P4 逐库扩展，不等待最难的客户端库才能使用已完成的 API 通道。
