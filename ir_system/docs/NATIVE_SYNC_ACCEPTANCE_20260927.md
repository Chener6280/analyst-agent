# 北京时间当日同步：本轮验收

## 已实现

- 星球／IMA 原范围自动续批；网络短暂异常最多重试 3 次；后台浏览器中断恢复一次。
- 资料／附件的可隔离失败保留缺口，不再拖停其他资料；解析需 OCR 不停止后续解析或调用付费接口。
- IMA macOS 官方客户端辅助功能接入更新按钮。API 220021 额度耗尽后转客户端；
  原 API 断点保留，不复制 Cookie，不调用隐藏接口，不绕过官方禁止导出。
- 选择范围和日期不变；日期按 Asia/Shanghai，客户端列表日期与真实发布日期区分。
- 客户端目录位置与已处理行持久化，原件通过公开 ir_search 接口按稳定 ID／哈希入库。
- 登录、辅助功能授权、焦点丢失、平台限制、无法识别的目录结构仍明确报告；不是“永不失败”。

- Node 单元／集成测试：139 项通过。

  使用隔离配置和替身下载器，没有修改生产任务或订阅选择。
- 真实无头浏览器：9 个本地合成页面、6 次附件保存、3 次启动，会话保持通过；无线上信源调用。

## 不应据此宣称

没有跑完生产选择的 34 个星球和 4 个 IMA 库的全部当日任务。未验证所有 IMA 客户端布局、
文件夹或无扩展名内容的完整导出。短日期年份仍有推定；无法证明平台级全量。
遇到不能确认的内容保留缺口，最终结果可能是 partial，不会标为全量完成。

## 应用部署

构建：`release/native-daily-update-preview/mac-arm64/IR System.app`。
打包时编译目标架构的 Swift 辅助功能程序。首次使用由本人授予系统权限。
旧版已打开的窗口不会自动热替换，必须退出后从更新后的桌面快捷方式重新打开。
没有强行退出用户正在使用的旧窗口或命令行会话，没有清空生产断点或删除原件。
