## 2026-09-27 第九版：IMA 定点复检与目录续查

本节优先于下方旧版本。默认“联网复检待处理库”只处理没有有效通过证据的已勾选库；单行“单库复检／继续找样本”可独立执行。每次仍刷新完整订阅目录，新的订阅／权限变化照常要求确认。其他库的有效证据不无故失效；主动复检目标的旧证据废止，但本次已经完成并保存的真实结果可在中断后保留。

“样本／诊断详情”提供同一文件的标题、稳定引用、所在文件夹 ID、核验时间及脱敏数字错误码，便于官方客户端核验。IMA 客户端下载自动化仍未接入；人工文字报告不能将权限设为绿色。下载前勾选排除规则沿用第八版。协议细节及安全边界见 `DOWNLOAD_PREFLIGHT.md`。

## 2026-09-27 第八版：问题勾选与真实范围排除

本节优先于下方旧版本。预分析的每个问题默认带已勾选的复选框。库／栏目级问题可取消：这会将对应范围设为不采集，历史更新、最新更新、IMA 复检、提示词范围和新任务计划一起排除它们。不是只隐藏错误，也不是赋予权限。一个问题影响多个库时，界面说明数量；取消会排除全部对应范围。

绿色只表示剩余非空已选范围通过当前已知检查；有排除项时明确显示其数量。全部取消显示“未选择范围”，不假装成功。归档锁、账号／完整扫描、本机环境、通道未接入等没有可安全缩小范围的系统必检项仍显示勾选，但不可取消。用户不能以忽略错误绕过平台权限、复用旧授权或把未完成任务标成成功。

新任务与授权续传继续验证实际范围；范围变化撤销未使用的授权。已有失败／暂停任务、原始归档、断点、水位和历史证据不修改。问题原因区分未找到样本、上游未分类错误和本轮未检查；未检查不再显示任务结束时间为核验时间。

## 2026-09-27 第六版：网页通道接入更新按钮，预处理独立

本节优先于下方旧版本。知识星球同一批已选范围内，Skill 可用的走公开 API；未启用 Skill、会员有效且允许下载的自动走固定 `zsxq_web`，无需模型。两条路线由同一个桌面任务串行调度，共用预算、日志和授权续传。全部订阅仍每次重新核验；会员到期、禁下载、状态变化均不会绕过。

“预处理提示词”从预分析弹窗打开，是一份没有日期、没有语音分类的前置处理合同。需要扫码时，提示词要求执行工具直接打开本机已有登录入口，等待用户本人完成。桌面预分析也会在所选网页星球经完整近期扫描确认后自动核验专用浏览器登录；需要时直接显示二维码，不复制 Safari 登录数据，不启动下载。没有执行工具的模型必须报告能力缺失。后续实际 LLM 处理仍保留非语音／语音两份提示词与日期。

### 下载与断点

- 网页程序先按真实文件元数据排除音频、视频；具名附件登记待办，已有音频原件不丢弃。未知类型（包括可能混合媒体的压缩包）、未知大小或超过单文件预算的文件停下报告，不盲目下载。
- 网页读取和下载只通过正常浏览器操作，标题、日期和文件大小可使用正常浏览产生的响应；不重放私有接口，不保存签名 URL，不截图。禁止复制正文时仅保存元数据。
- 网页导航／滚动／下载启动动作与 API 操作共用内容操作预算；完整会员扫描仍是独立预检。字节预算是原件落盘量，网页自动加载、临时传输和失败请求不能承诺网络流量硬封顶。网页发现历史本身会占预算，预算太低可能需提高后授权续传，不能自动扩大。
- 桌面拥有独立的 `desktop-*` 网页检查点，标识包含桌面任务、日期、范围、权限及媒体策略；不改旧 CLI 年度检查点。已有原件校验后复用，新任务仍重新发现内容，不继承旧任务的“已完成”。
- 已存的 `zsxq_web` 资料通过 ir_search 的公开本地索引／检索／解析接口入库，解析只选本任务引用的非音频附件。预算暂停或网页登录中断保存桌面与网页断点，原任务授权续传；未知错误、权限问题仍交维护者。
- 网页图片原件／原生播放器音频没有伪装成已下载：普通图片保留发现数量与覆盖缺口，具名可下载文件按权限处理。网页无限滚动始终 `coverage_complete=false`。复制禁止导致的元数据不升级为正文。

仅修改 `ir_system`，未修改 `ir_search` 或真实归档。预处理合同见 [DOWNLOAD_PREFLIGHT.md](DOWNLOAD_PREFLIGHT.md)。输出为 `release/source-web-sync-preview/mac-arm64/IR System.app`，保留旧包。

验收范围：合成会员／权限及浏览器、真实临时文件与 SDK 本地索引解析，验证 API／网页共用预算、两种日期模式、断点、非音频过滤、扫码登录不启动下载。桌面验收使用隔离配置，并核验打包后的固定网页桥接依赖；未使用真实账号下载。实际网站页面、限流和账号登录仍须用户授权的小范围在线验收。未签名／公证，当前仅 macOS arm64。

## 2026-09-27 第五版：统一预分析，随后执行下载

本节优先于下方历史说明。全部五个信源共用“预分析”状态列，与 LLM 提示词分开；历史与最新共用检查，不依赖所填日期。信源清单在主进程和界面间共享，新增信源也不会默认为绿色。

- 绿色“可更新”：已选范围的已知前置检查通过。须有完整且最近 24 小时内的订阅／栏目扫描、明确的选项与已知权限、已接入的桌面下载通道、无重叠未解决桌面任务，以及最近 10 分钟内通过的本地环境检查。
- 琥珀色“需处理”：点击逐项查看原因与下一步，包括会员到期、平台禁止下载、网页通道未接入、待确认问号、扫描失败或未完成任务。处理后必须重新核验，不能把 Agent 的文字报告作为成功状态。
- 灰色“待核验／待接入”：证据不足或下载路线尚未接入。阿尔法派和冈底斯不会因没有已知错误就变绿。
- 检查只针对已勾选范围；未勾选的过期订阅不阻塞。新订阅／状态变化的问号仍需明确选择成 ✓ 或 ×。来源目录可见不等于每个原件可下载；绿色不是历史齐全的证明。
- 点击预分析会读取本地状态并核验 Python、公开 SDK 的非音频下载能力、解析依赖、归档目录和写入占用，不联网、不下载、不调用模型、不删除锁。重新扫描订阅另需明确联网确认。检查只保存在内存，重启或配置变化须重新检查。
- 归档根目录的 `.writer.lock` 使用系统文件锁，空文件存在不等于被占用；派生索引目录的 `.writer.lock` 是排他哨兵，存在会阻碍解析。不能混为一谈，也不能让 Agent 一律删锁。

使用顺序：处理预分析问题 → 重新扫描并确认订阅选择 → 检查本地环境 → 绿色后确认日期和预算，执行“更新历史”或“更新到最新”。真正执行仍再次预检；未完成的重叠桌面任务按原任务授权续传，不能新建任务绕过失败。绿色仅针对文字与非音频阶段；音频待办不会单独阻塞其变绿，也不由绿色授予音频下载或转写权限。

LLM 保留独立的非语音／语音提示词。普通下载不用模型；需要 Computer Use 或 OCR 时可在非语音阶段介入，语音仍在非语音阶段验收后另行授权。Pi 在外部执行归档 CLI 的结果不会自动接通桌面网页路线，也不会自动变成桌面任务完成记录。提示词强调用户本次日期优先于恢复文档里的年度示例，旧断点范围不符须先报告。

输出：`release/source-health-preview/mac-arm64/IR System.app`。保留旧包；本轮使用隔离配置与合成订阅、锁、任务验证，不进行真实来源扫描、下载或模型调用。

验收：Node 48 项、Python 19 项，以及 Electron 开发版／macOS arm64 打包版界面通过。覆盖绿色→琥珀色刷新、未知权限不变绿、取消联网确认不创建任务、非语音／语音提示词独立和两标签真实终端。未签名／公证，其他系统未验收。

### 仍然存在的采集边界

勾选是更新意向，不是平台授权。实际下载前再次检查订阅。会员到期、下载禁止、订阅状态变化、网页通道需求或目录访问受限会暂停，不能由 LLM 绕过。知识星球网页 CLI、IMA 客户端和音频转写尚未由普通“更新”按钮自动执行；LLM 按钮提供交接提示词而非伪造下载成功。阿尔法派、冈底斯的历史／增量按钮仍禁用。

每次知识星球全量会员检查是独立、有界的订阅预检（最多目录返回的 200 个群），随后内容下载使用本轮接口预算；UI 授权说明区分两者。总运行时间预检后扣除。遇到认证、限流或意外错误停止，不切换账号或绕过限制。

## 界面与使用

- 去掉 Demo／Adapter 选择卡片；默认使用 ir_search。旧配置中的 Demo 不再作为正式默认值。连接路径在顶部「连接设置」中折叠显示。
- 固定五行：IMA、知识星球、智堡、阿尔法派、冈底斯。
- IMA／知识星球点击子信源选择，可扫描当前订阅，选择一次性／持续更新／不采集，填写首次起点。新目录条目默认待选择。IMA Excel 仍是只读预览，明确绑定真实 ID 后可应用标记；原表不修改。
- 智堡不在主表展示子栏目选择。首次更新需明确确认全部九栏目的范围与更新方式；既有栏目配置不自动扩充。
- 每行「更新历史」可选起止日期；「更新到最新」仅使用这个信源的持续更新集合。无日期能力的 IMA 仍是目录枚举去重，界面明确提示不能严格按所填日期筛选。
- 「信息截止于／覆盖」可点击，分开查看本地最新资料日期、目录扫描、每集合增量检查位置与历史回补范围。已有 CLI 归档不被推断为桌面任务已经完成。
- 运行中可在任务日志停止；预算暂停、中断与正常停止可授权续传。失败仍不自行绕过。

## 工作窗口

- 任务日志：真实程序统计与状态，不使用模型。
- 整理助手：现有 Pi 脱敏任务报告解释入口，每次单独确认模型额度；没有正文读取／分类／摘要权限。
- CLI 设置：保存 Pi、Kimi、其他 CLI 的本机程序路径。Pi 沿用其保存的默认模型；Kimi／其他路径只保存、不执行，界面标明待接入。
- 输入框仅支持 `/help`、`/status`、`/report` 三种固定指令。不是原生交互式终端，也不会执行任意 Shell 或自动安装程序。正文整理和完整 CLI 会话后续接入。
- 日志／助手内容区可从右下角拖动增高，或在区内滚动。连接配置与本地归档处理队列默认折叠。

## 程序边界

阿尔法派、冈底斯只有既有搜索／读取能力，未接入统一历史与增量采集；两个更新按钮保持禁用，后端也拒绝为它们创建同步计划。

历史回补允许对已启用的一次性或持续更新集合执行显式日期范围，单独保存历史检查区间，不移动增量检查位置。一次小范围回补不会自动标为一次性历史全量完成。

相同归档内，未解决任务阻止重叠集合创建新任务；其他信源可以在空闲时单独执行。运行互斥、预算、重新扫描、原件哈希校验、音频排除和公开 SDK 隔离保持不变。

此轮只修改 ir_system，没有修改 ir_search 源码或实际归档内容。模型不获得任意终端权限；UI 窗口也不是操作系统沙箱。
