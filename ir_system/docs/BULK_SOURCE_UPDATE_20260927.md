# 多信源操作与 9 月 27 日核对

## 本版行为

- 每个信源左侧勾选框只控制合并操作范围，保存在本机；不改变子订阅选择。
- 合并核验：一次确认扫描所选已接入信源，随后检查本地环境和所需星球登录；展示逐信源问题，可生成合并修复提示词。阿尔法派、冈底斯仍为待接入，不冒充可下载。
- 合并历史／最新：共享北京时间日期范围，仅包含已选信源下的持续更新子订阅。任何所选信源未接入或没有范围则要求处理，不静默跳过。一个任务、一份确认、独占归档写入、自动续批；不是多个下载器并行写入。
- 合并 LLM：非语音与语音各一份独立提示词；同一阶段按信源依次执行。生成、复制都不代表执行或付费授权。
- 顶部四地时钟使用 Asia/Shanghai、Asia/Tokyo、Europe/London、America/New_York，自动处理夏令时和跨日。
- 通过 ir_search 公开音频接口读取真实活动调用，显示来源、文件、完成秒数／总秒数和“转写中”。需要存活进程、匹配写锁、当前 in-flight 调用共同证实；部分转写或崩溃遗留状态不冒充运行中。刷新不调用模型。

## IMA 授权修复

原实现弹出 macOS 授权框后立即以 ima_accessibility_required 退出，授权后无自动恢复；且授权检查若恰好成功，仍可能重新抛出旧异常。

现修复两处：已获得授权后继续；尚未获得则释放下载写锁，桌面显示等待授权，每 2 秒只读检查一次，最多 90 次。成功后恢复同一任务与断点；停止按钮有效。仍未获得授权则保留断点，用户可在任务日志中授权续传。程序不自行勾选系统权限，不反复弹框。

独立同版本应用检查返回 ready。尚未通过新版本实际生产任务证明全部 IMA 库下载完成。macOS 更新路径／应用身份变化仍可能要求用户重新授权；退出旧应用并打开桌面新版本后，以任务实际检查结果为准。
